## 📖 Overview

**From Bench to Biosphere** is a self-contained, single-file HTML analytical brief that frames the problem of hazardous industrial chemicals through the lens of pharmaceutical-style natural-product discovery. It argues that the same toolkit used to find drugs in plants — high-throughput screening, structure–activity modeling, ADMET profiling — can be repurposed to identify greener solvents, safer flame retardants, kinder pesticides, and more.

The document is designed as a **print-ready, offline-capable web brief** — no build step, no dependencies to install, no backend required. Just open the `.html` file in any modern browser.

## ✨ Features

- 📄 **Single-file deployment** — everything (HTML, CSS, JS, fonts, charts) loads from CDNs
- 🎨 **Editorial design system** — paper-grain textures, serif/sans pairing, custom color palette
- 📊 **Two interactive Chart.js visualizations**:
  - Comparative TRL (Technology Readiness Level) bar chart
  - Performance-vs-hazard bubble chart for the five chemical classes
- 🧭 **Smooth anchor navigation** with sticky header
- 📱 **Fully responsive** (mobile, tablet, desktop)
- 🌱 **Five detailed case studies** with collapsible research snapshots
- 🔬 **Six-stage pipeline diagram** translating drug discovery to green chemistry
- 🎯 **Three synthesized takeaways** for researchers and policymakers
